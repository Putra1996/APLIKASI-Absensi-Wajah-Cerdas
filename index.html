Sesi terautentikasi

Akun dibuat oleh administrator di Supabase Auth, lalu ditambahkan ke daftar petugas school_staff. Pendaftaran mandiri tidak diaktifkan.

Penting untuk data biometrik

Aplikasi ini memakai login petugas dan RLS; skrip SQL menolak akses anon serta menyimpan foto di bucket privat. Admin tetap harus membuat akun dan mengotorisasi UUID petugas. Foto serta descriptor hanya diproses bila persetujuan orang tua/wali diverifikasi. Ini langkah teknis, bukan pengganti penilaian hukum, DPIA, prosedur insiden, atau kebijakan retensi sekolah.

Langkah awal

  1. 01Buat project Supabase khusus sekolah, pilih region setelah meninjau lokasi pemrosesan data, lalu jalankan supabase.sql.
  2. 02Buat akun petugas di Auth → Users dengan sign-up publik nonaktif. Masukkan UUID akun pertama sebagai admin ke school_staff melalui SQL Editor.
  3. 03Hubungkan URL + anon/publishable key, lalu login. Daftarkan roster siswa; aktifkan biometrik hanya setelah persetujuan tertulis diverifikasi.
  4. 04Uji kamera/Realtime di jaringan sekolah; petugas mengonfirmasi setiap kandidat atau menandai hadir manual.
Kamera memerlukan konteks aman: gunakan HTTPS atau localhost. Model wajah dan library dimuat dari CDN, jadi browser perlu koneksi internet.
